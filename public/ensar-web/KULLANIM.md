# Ensar Hediyelik web görselleri

## Logo

`logo/ensar-logo-seffaf.png` eski sitedeki orijinal yatay logonun sıkı kırpılmış şeffaf PNG hali. Krem üst menüde kullan. `logo/ensar-logo-beyaz.png` aynı logonun koyu alt menüye uygun beyaz sürümü. `logo/favicon.png` EH simgesi. Kaynak: https://www.ensarhediyelik.com.tr/image/catalog/flowers/logo.png

Tasarım örneğindeki iki satırlı yazı ile firmanın yatay logosu farklıdır. Web sitesinde üst menü genişliğini yatay logoya göre ayarla.

| Bölüm | Dosya |
| --- | --- |
| Açılış 1 | gorseller/hero-astronot-cam-kure.webp |
| Açılış 2 | gorseller/hero-balerinli-piyano.webp |
| Açılış 3 | gorseller/hero-solmayan-gul-fanusu.webp |
| Hediyeni Bul örnek sonucu | gorseller/hediye-sonuc.webp |
| Kategori kartları | gorseller/kategori-*.webp |
| Yeni Gelenler kartları | gorseller/urun-*.webp |
| Işıklı Hediyeler | gorseller/vitrin-isikli-hediyeler.webp |
| Menü ve kontroller | ikonlar/*.svg |
| Görsel karşılaştırma | referans-kadrajlar/*.webp |

`gorseller/` içindeki WebP dosyaları tasarıma göre yeniden üretilmiş konsept fotoğraflardır. Katalogdaki gerçek ürün fotoğrafıyla değiştir veya önizlemede “Konsept görsel” etiketini göster. `referans-kadrajlar/` içindeki küçük kırpmalar önceki tasarımdan alınmıştır ve görsel eşleştirmeye yarar.

Açılışta fotoğrafı sağ panele yerleştir. Sol mürdüm zemin, başlık, buton ve slayt okları HTML/CSS öğesi olsun. Mobilde aynı fotoğrafı başlığın üstünde kullan. Fotoğrafları büyütürken ürünün cam üstünü ve tabanını görünür bırak. Vitrinde fanusu sağda, başlığı solda tut. AntiGravity'de önceki prompttaki ilgili yol ve dosya adlarını bu tabloyla güncelle.
